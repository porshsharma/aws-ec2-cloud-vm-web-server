# AWS EC2 Cloud VM Web Server

A web server deployed on an AWS EC2 virtual machine running Ubuntu as part of my Cloud Computing Internship.

## Project Overview

The objective of this project was to deploy a web server on a cloud virtual machine and make the hosted webpage publicly accessible.

## Technologies Used

- Amazon EC2
- Ubuntu
- Apache
- HTML/CSS
- SSH
- AWS Security Groups

## Architecture

Internet
↓
AWS EC2
↓
Ubuntu
↓
Apache Web Server
↓
HTML Webpage
↓
Public IP

## Workflow

1. Created an AWS EC2 instance.
2. Configured the security group.
3. Connected to the Ubuntu virtual machine.
4. Installed Apache web server.
5. Created and deployed the webpage.
6. Configured HTTP access on port 80.
7. Tested the website using the EC2 public IP.
